Configuração inicial da nuvem privada (uma única vez)
  1. Crie um projeto no Supabase e copie a URL do projeto e a chave publicável/anon em Project Settings / API.
  2. No SQL Editor do Supabase, execute o SQL abaixo para criar a tabela privada e as regras de acesso.
  3. A URL, a chave publicável e o e-mail já estão preenchidos. Clique em Salvar configuração. A senha solicitada é a senha do usuário Supabase Auth (criada por você), não a senha do banco de dados. Use Criar conta uma única vez; depois confirme o e-mail, se solicitado, e utilize Entrar nos demais dispositivos.
  4. No dispositivo que contém os dados corretos, clique em Enviar dados deste dispositivo na primeira sincronização. Nos demais, entre com a mesma conta e escolha carregar os dados da nuvem.
create table if not exists public.finance_insight_sync (
  user_id uuid primary key references auth.users(id) on delete cascade,
  payload jsonb not null,
  updated_at timestamptz not null default now()
);

alter table public.finance_insight_sync enable row level security;
grant select, insert, update on public.finance_insight_sync to authenticated;

drop policy if exists "Read own Finance Insight data" on public.finance_insight_sync;
create policy "Read own Finance Insight data" on public.finance_insight_sync
  for select to authenticated using ((select auth.uid()) = user_id);

drop policy if exists "Insert own Finance Insight data" on public.finance_insight_sync;
create policy "Insert own Finance Insight data" on public.finance_insight_sync
  for insert to authenticated with check ((select auth.uid()) = user_id);

drop policy if exists "Update own Finance Insight data" on public.finance_insight_sync;
create policy "Update own Finance Insight data" on public.finance_insight_sync
  for update to authenticated using ((select auth.uid()) = user_id)
  with check ((select auth.uid()) = user_id);

Segurança: use somente a chave publicável/anon. Nunca cole a chave service_role neste painel. A proteção dos dados depende das políticas RLS acima e do login na mesma conta em todos os dispositivos.
